Worth noting for the chapter
- The dialog cuts the manufacturer's answer off at ..."name":\"Ha. That's VBA's
  Left(resp, 200), so the user never sees the part of the request that broke.
- The mock's console shows only "400 malformed JSON". Its transcript also logged the
  parser's own error, which never appears on screen:
    Invalid object passed in, ':' or '}' expected. (81): {"dealer":"CAIRN",...,"shipTo":{"name":"Harlow "Old Mill" Manufacturing",...}
  Position 81 falls on "Old", just after the quote that ends the name string early
  (the O if the parser counts from 1, the l if from 0).
- The response body Access stored escapes the apostrophes as '. That's
  ConvertTo-Json in PowerShell 5.1 encoding the parser's message.
